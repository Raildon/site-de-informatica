Como instalar o Windows XP passo a passo

Aprenda a criar um pendrive bootável e conheça as etapas da instalação do Windows XP, desde a preparação da mídia até a configuração inicial do sistema.

Antes de começar

Atenção: o Windows XP não recebe atualizações de segurança atuais. Utilize-o para estudos, testes ou em equipamentos antigos e isolados da internet.

A instalação pode apagar os arquivos do disco selecionado. Faça backup de todos os documentos importantes antes de iniciar o procedimento.

  • Pendrive de pelo menos 2 GB;
  • ISO legítima do Windows XP;
  • Chave de produto válida;
  • Computador compatível;
  • Rufus para preparar a mídia.

1. Baixar o Rufus

O Rufus é uma ferramenta utilizada para criar pendrives inicializáveis a partir de imagens ISO.

Acesse o site oficial: Baixar Rufus

O Rufus não precisa de uma instalação tradicional: normalmente basta baixar e executar o arquivo.

O instalador do Windows XP não foi originalmente projetado para funcionar por USB. Por isso, a criação de um pendrive de XP pode apresentar incompatibilidades.

2. Conectar o pendrive

Passo 1: conecte o pendrive ao computador.
Passo 2: abra o Rufus.
Passo 3: confira se o Rufus selecionou o pendrive correto.
O processo pode apagar todos os dados do pendrive. Salve seus arquivos antes de continuar.

3. Selecionar a ISO do Windows XP

Passo 1: localize a opção para selecionar a imagem ISO.
Passo 2: clique em Selecionar.
Passo 3: escolha a ISO legítima do Windows XP.
Passo 4: confira as opções exibidas pelo Rufus antes de iniciar.

4. Criar o pendrive bootável

  1. Confirme o pendrive selecionado.
  2. Confira se não existem arquivos importantes nele.
  3. Clique em Iniciar.
  4. Leia e confirme os avisos apresentados.
  5. Aguarde o término do processo.
  6. Feche o Rufus quando a operação terminar.
Dica: se o Rufus apresentar opções específicas para a instalação do XP, leia as instruções exibidas e verifique a compatibilidade com o seu computador.

5. Iniciar o computador pelo pendrive

Agora, conecte o pendrive ao computador onde deseja instalar o Windows XP.

  1. Reinicie o computador.
  2. Abra o menu de boot ou a BIOS.
  3. Procure a opção do pendrive.
  4. Selecione o pendrive e pressione Enter.

A tecla de acesso pode variar. Alguns computadores utilizam F12, F11, F9, Esc ou Del.

Computadores antigos geralmente utilizam BIOS Legacy. Equipamentos modernos podem não ser compatíveis com o Windows XP.

6. Iniciar o instalador do Windows XP

Depois de iniciar pelo pendrive, o instalador poderá carregar arquivos e mostrar a tela azul de instalação.

Passo 1: aguarde o carregamento dos arquivos.
Passo 2: na tela inicial, pressione Enter para iniciar a instalação.
Passo 3: leia o contrato de licença e pressione F8, quando solicitado, para continuar.

7. Escolher a partição

Uma partição é uma área organizada do disco. O Windows será instalado na partição escolhida.

  1. Observe as partições apresentadas.
  2. Identifique o disco correto.
  3. Escolha a partição destinada ao Windows XP.
Não exclua ou formate uma partição sem confirmar que seus arquivos importantes estão salvos.

8. Formatar a partição

A formatação prepara a partição para receber os arquivos do sistema operacional.

  1. Selecione a opção de formatação desejada.
  2. Leia o aviso apresentado pelo instalador.
  3. Confirme somente depois de verificar o disco correto.
  4. Aguarde o término da formatação.

O Windows XP pode utilizar sistemas de arquivos como NTFS e FAT. O NTFS é uma opção comum para instalações do Windows XP.

9. Cópia dos arquivos

Depois da formatação, o instalador copia os arquivos necessários para o disco.

  1. Os arquivos de instalação são copiados.
  2. O computador pode reiniciar.
  3. A instalação continua automaticamente.
  4. Novas telas de configuração serão exibidas.
Se o computador reiniciar e voltar ao começo da instalação, verifique a ordem de inicialização e o pendrive conectado.

10. Configuração inicial

Durante essa etapa, o instalador solicitará informações para concluir a instalação.

  • Idioma e região;
  • Nome do usuário;
  • Nome do computador;
  • Chave de produto, quando solicitada;
  • Data e horário;
  • Configurações de rede.
Passo 1: preencha as informações solicitadas.
Passo 2: aguarde a conclusão da instalação.
Passo 3: acesse a área de trabalho do Windows XP.

11. O que fazer depois da instalação?

Depois de instalar o Windows XP, pode ser necessário instalar os drivers compatíveis com o computador.

  • Driver de vídeo;
  • Driver de áudio;
  • Driver de rede;
  • Drivers do chipset e da placa-mãe;
  • Configuração de data e horário;
  • Ativação com uma chave válida.
Antes de formatar, procure os drivers compatíveis com o modelo do computador e com a versão do Windows XP.

Conclusão

A instalação do Windows XP envolve a criação do pendrive bootável, a inicialização pelo USB, a escolha da partição, a formatação, a cópia dos arquivos e a configuração inicial.

Como o sistema é antigo, a compatibilidade com computadores modernos pode ser limitada. Faça o procedimento em um equipamento de testes e mantenha seus arquivos protegidos.
